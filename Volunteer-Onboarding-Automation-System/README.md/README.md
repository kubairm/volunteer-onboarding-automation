# Volunteer Onboarding Automation System

## Overview

A low-code volunteer management automation solution built with Microsoft Power Automate, SharePoint, and Microsoft Teams. The workflow streamlines onboarding by automatically processing volunteer submissions, applying conditional logic to categorize volunteers by program area, routing information to the appropriate teams, and sending automated notifications to relevant stakeholders.

## Features

- Automated volunteer submission processing
- SharePoint integration for data management
- Conditional workflow logic
- Program area-based routing
- Microsoft Teams notifications
- Automated email communication

## Technologies Used

- Microsoft Power Automate
- Microsoft SharePoint
- Microsoft Teams
- Microsoft Outlook

## Workflow

1. A new volunteer record is created in SharePoint.
2. The workflow checks volunteer status.
3. Volunteer information is categorized based on program area.
4. Relevant teams are notified automatically.
5. Email communication is sent to stakeholders.

## Purpose

This project demonstrates how low-code automation can improve operational efficiency by reducing repetitive administrative tasks and improving communication workflows.
